# Keyframe self-check / 自查清单

Save at least these stills, then open them (do not judge only by whether the GIF compiled):

- Wind-up (the most stretched or crouched pose)
- Impact (frame 0)
- Peak (the picture that hitstop should freeze)
- Dissipate (mid, not the last empty frame)
- Optional: recovery / leftover ground marks

Score each item yes / no / n/a, and fix a **single** iteration if several are no.

## Common failures

- Filled concentric color shells instead of a **hollow** shock ring
- A symmetric 16-petal flower instead of irregular tongues or lobes
- A spatial hash that cuts **blocky** notches in the silhouette
- White core hidden by a star spark or a full-white victim
- Peak ring so gappy or off-screen it no longer reads as a ring
- Smoke stuck on the caster's sprite
- Using a full-screen black-and-white invert on a mid-tier move
